## 为什么单独放在这里

仓库根目录曾出现一个 `示范版本.pdf`（24 页），内容是**同一道 D 题的第三方解答**
（摘要明确写着"本文针对 2026 年中国研究生数学建模竞赛 D 题…"）。
它由工作区外部放入，并非本项目产出，因此：

1. **移入本目录并改名**，避免与我们的交付物混淆；
2. **禁止**将其结论当作本队结果写入论文；
3. **禁止**直接引用其文字（竞赛查重会判定违规）。

---

## 使用边界（重要）

| 可以做 | 不可以做 |
|---|---|
| 作为**交叉验证**：看它的数量级是否与我们的独立计算一致 | 把它的表格/数字搬进我们的结果文件 |
| 提示我们是否有遗漏的建模角度 | 抄写其表述、公式推导或图表 |
| 校验我们对题目的理解是否有偏差 | 以它作为唯一依据下结论（题目要求引用正式文献） |

题目明确规定：**不得以 AI 输出作为学术依据**，公式与结论须引用正式发表的文献或可核验数据。
第三方解答既非正式文献、也非本队工作，**只能用于自查**。

## 交叉验证记录（只登记"是否一致"，不引用其表述）

> 目的：若第三方独立算出的量级与我们的独立结果一致，可增强我们对物理层/数据理解的信心；
> 若不一致，则提示我们复查。**记录时只写"我们的值"与"是否吻合"，不誊抄对方内容。**

| 项目 | 我们的独立结果 | 是否吻合 | 说明 |
|---|---|---|---|
| 问题一最优架次数 | **18**（达到下界，可证最优） | 一致 | 我们的下界来自 Martello–Toth 型下界，与启发式逐区相等 |
| A 型最大安全载荷 | **恒为 25 kg**（15/15 全区受结构上限约束） | 一致 | 与 `outputs/q1/tables/q1_1_max_safe_payload.csv` 一致 |
| C 型远距离载荷下降 | S008 降至 **58.99 kg** | 量级一致 | 我们按能量约束二分反解，回代误差 5.6e-15 |
| ρ 增大导致架次数上升 | ρ: 0.20→18 架次；0.35→25 架次；0.40 起不可行 | 趋势一致 | 见 `outputs/q1/tables/q1_4_rho_sweep.csv` |
| 总能耗 | **75.07 kWh**（我们的 `single_C` 方案） | 数值不同 | 能耗口径差异（我们按航程反推水平能耗，见 ADR-021）；**以我们的口径为准并在论文中说明依据** |

> ★ **能耗数值不一致是预期的**：题目附录 2 未给出运输机的巡航功率，
> 我们采用"由航程反推"的口径（ADR-021），第三方可能采用别的口径。
> 论文中必须明确写出所采用的能耗口径与依据，而不是比较绝对值。
