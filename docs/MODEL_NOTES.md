### 1.2 冲突定义与消解

**待定**：冲突的**可计算数学定义**。

**候选思路**（待评估）：
- 定义指标间秩相关矩阵 `R`，对某样本 `j`，若存在指标对 `(a,b)` 使

- 或定义"方向一致性得分"，用稳健聚合（截尾均值 / 中位数）消解。

**待填**：冲突判定的阈值 τ 及其依据；扩展集上的结论一致性检验。

### 1.3 配比建模（核心）

**模型形式**：`Loss = f(p)`，`p ∈ Δ¹⁶`（17 维单纯形）。

**选择：ILR 变换 + 岭回归**（ADR-002）

中心化对数比变换（CLR）：
```
clr(p)_i = ln(p_i) − (1/D) Σ_j ln(p_j),   D = 17
```
等距对数比（ILR）把 `Δ¹⁶` 等距映射到 `ℝ¹⁶`，在变换空间做岭回归可避免：
- 原空间线性回归的设计矩阵共线（`Σp_i = 1` 导致严格共线）
- 边界解（`p_i = 0`）导致 `ln` 无定义 → 需零值替换（乘性替换 / 贝叶斯乘性替换）

**待填**：正则强度 λ 的选取（交叉验证）、零值处理方式、各领域系数及其组合效应。

## Q2 跨维度数据融合与广义标度律

### 2.1 经典基线

```
L(N, D) = E + A·N^(−α) + B·D^(−β)
```
用 B1 拟合，参数报告形式：`θ̂ ± se`，附 95% 置信区间（`lmfit`）。

### 2.2 广义标度律 L(N, D, Q, p)

**设计要求**：`Q = 1` 且 `p` 为参考配比时**退化为经典形式**。

**候选形式**（待选定与论证）：

形式一（质量作为乘性调制）：
```
L(N,D,Q,p) = E + A·N^(−α)·Q^(−γ) + B·D^(−β)·Q^(−δ)
```
`Q = 1` 时退化为经典形式 ✓

形式二（质量进入有效数据量）：
```
L = E + A·N^(−α) + B·(D_eff)^(−β),   D_eff = D · Q^κ
```

形式三（配比作为有效数据量的重加权）：
```
D_eff = D · Σ_i p_i · q_i,   q_i 为领域 i 的质量权重
```

**待填**：最终选定的形式、参数估计、拟合优度对比（AIC/BIC）、兼容附件 A 与附件 B 两套独立实验的**可检验假设**。

### 2.3 弹性与替代条件

边际效用（弹性）：
```
ε_N = ∂ln L / ∂ln N = −α·A·N^(−α) / L
ε_Q = ∂ln L / ∂ln Q
```

**"质量提升 0.1 等价于参数增加多少"的可计算条件**：
在算力固定下，令 `d ln L = 0`：
```
ε_N · d ln N + ε_Q · d ln Q = 0
⇒ d ln N = −(ε_Q / ε_N) · d ln Q
⇒ ΔN / N = (Q'/Q)^(−ε_Q/ε_N) − 1
```
**待填**：代入估计参数后的数值结果与区间。

### 2.4 领域替代/互补关系

用 Hessian 交叉偏导 `∂²L / (∂p_i ∂p_j)` 的符号判定：
- 负 → 互补（一起增加收益更大）
- 正 → 替代

**待填**：显著非零的交叉项清单与物理解释。

## Q3 算力约束下的多维资源联合优化与结构性转移

### 3.1 优化模型

```
min  L(N, D, Q, p)
s.t. C_total = 6ND + D·[g(Q) − g(Q0)]⁺ + η·N·D·L_ctx ≤ C
     N > 0, D > 0, Q ∈ (0, 1],  Σp_i = 1, p_i ≥ 0
     η = 2×10⁻⁴,  L_ctx 外生（依据 C7）
```

### 3.2 g(Q) 三种形式（附录 B）

| 类型 | 形式 | 参数 |
|---|---|---|
| 指数型 | `g(Q) = γ·e^(λQ)` | γ = 10⁷, λ = 6.0 |
| 幂函数型 | `g(Q) = γ·Q^λ` | γ = 5×10⁹, λ = 4.0 |
| 对数渐进型 | `g(Q) = γ·ln(1+λQ)` | γ = 2×10⁹, λ = 10.0 |

### 3.3 临界上下文长度（解析推导，必答）

令注意力开销与训练开销相当：
```
η·N·D·L_ctx = 6·N·D
⇒ L_ctx^crit = 6 / η = 6 / (2×10⁻⁴) = 3×10⁴ = 30000
```
**结论**：`L_ctx > 30000` 时注意力开销超过基础训练开销，成为算力预算的主导项。
**待填**：在 C7 给出的可行取值集合上的敏感性分析表与图。

### 3.4 结构性转移：定义与识别

**定义**（待论文中正式化）：
设预算 `C` 的最优资源配置映射 `C ↦ x*(C) = (N*, D*, Q*, p*)`。
若存在 `C₁ < C₂` 使 `(C₁, C₂)` 上 `x*(C)` 的**激活约束集合发生变化**（KKT 乘子中非零分量的支撑集改变），
或最优解的**主导维度发生切换**（以 `∂ln N*/∂ln C` 与 `∂ln Q*/∂ln C` 的相对大小刻画），
则称该预算区间发生**结构性转移**，分界点 `C*` 为转移点。

**识别方法（须全部实现并交叉印证）**：

| # | 方法 | 产出 |
|:--:|---|---|
| 1 | `log₁₀C ∈ [15, 27]` 网格扫描 | `(N*, D*, Q*, p*, 激活约束集, KKT 乘子)` 序列 |
| 2 | 弹性比值曲线 | `∂ln N*/∂ln C` vs `∂ln Q*/∂ln C` 的主序变化点 |
| 3 | 激活集变化点 | 各约束 KKT 乘子由 0 变正（或反之）的预算值 |
| 4 | `ruptures` 变点检测 | 对 `(N*, D*, Q*)` 序列的独立验证 |
| 5 | 简化情形解析解 | 仅含 `C_train + C_attn`、幂律损失时的闭式解 |

### 3.5 三种 g(Q) 下的最优配置对比

|---|---|---|---|---|---|---|---|
| 指数型 | 10¹⁹ / 10²² / 10²⁴ | 待填 | | | | | |
| 幂函数型 | 同上 | | | | | | |

### 3.6 ⚠️ 预研发现：Q3 的三个关键陷阱（**开工前必读**）

在 P3 正式建模前做过一次数值探针（用形式一损失 `L = E + A·N^(−α) + B·D^(−β)·Q^(−γ)`），
得到以下**会影响 Q3 建模策略**的结论：

#### 发现 1：大预算下 Q\* 强烈趋向边界，质量成本占比塌缩

用附录 B 的原始参数，取 `L_ctx = L_ctx^crit = 30000`、`Q0 = 0.5`：

| g(Q) | 预算 | N* | D* | Q* | 质量成本占比 | 训练占比 | 注意力占比 |
|---|---|---|---|---|---|---|---|
| 指数型 | 10¹⁹ | 2.53e8 | 2.09e9 | 0.878 | **36.5%** | 31.8% | 31.8% |
| 指数型 | 10²² | 4.18e9 | 1.85e11 | 1.000 | 7.1% | 46.5% | 46.5% |
| 指数型 | 10²⁴ | 3.11e10 | 2.65e12 | 1.000 | **1.0%** | 49.5% | 49.5% |
| 幂函数型 | 10¹⁹ | 3.78e8 | 1.10e9 | 0.994 | **50.1%** | 24.9% | 24.9% |
| 幂函数型 | 10²² | 4.25e9 | 1.80e11 | 1.000 | 8.4% | 45.8% | 45.8% |
| 对数渐进型 | 10¹⁹ | 2.51e8 | 2.37e9 | 1.000 | 28.7% | 35.7% | 35.7% |

**含义**：附录 B 的 γ 量级（1e7 / 5e9 / 2e9）使质量提升成本在**绝对**意义上很大，
但在 10²²、10²⁴ 预算下**相对占比塌缩到 1%~8%**，于是最优解把 Q 顶到上界 `Q = 1`。

**行动项**：
- **不要**把"Q\\*=1"当作建模错误或求解失败 —— 它可能是真实最优（角点解）。
- 必须按 OPS_SPEC 第 6.4 节要求，**显式讨论"边界解 vs 内点解"**：报告 Q\\* 命中上界的事实，
  并解释其经济含义（预算充裕时"把数据做到最好"比继续堆参数更划算）。
- 若希望得到内点解以展示更丰富的权衡，需要**论证 γ 的标定依据**，
  或改用"质量提升的边际成本随 Q 递增更快"的形式 —— 但这属于模型创新，须在论文中说明理由与依据。

#### 发现 2：质量损失弹性 γ 决定内点/角点，跨预算可能发生**符号级**的机制切换

扫描 `γ`（质量在损失中的指数）：

| γ | Q\* @10¹⁹ | Q\* @10²² | Q\* @10²⁴ | 是否存在内点解 |
|---|---|---|---|---|
| 0.2 | 0.50 ~ 0.62 | 1.000 | 1.000 | **是** |
| 0.6 | 0.878 ~ 1.000 | 1.000 | 1.000 | 部分 |
| 1.5 | 1.000 | 1.000 | 1.000 | 否 |
| 3.0 | 1.000 | 1.000 | 1.000 | 否 |

**含义**：`γ` 越大（质量对损失越重要），越应当把 Q 顶到上界；
只有当 `γ` 较小且预算较小时才出现内点解。
**结构性转移的"可观测信号"就藏在低预算区**（10¹⁹ 附近），而不在高预算区。

**行动项**：P3 的结构性转移扫描**必须覆盖 10¹⁸~10²⁰ 这个低预算区间并加密**，
不能只做题目建议的三档（10¹⁹/10²²/10²⁴）就下结论。

#### 发现 3：三种 g(Q) 在低预算下**给出定性不同**的最优解

在 10¹⁹ 预算下：幂函数型给 `Q* = 0.994`，指数型给 `Q* = 0.878`，**对数渐进型却给 `Q* = 1.000`**。

**含义**：对数渐进型 `g(Q) = γ·ln(1+λQ)` 在 `Q = 0.5` 附近的边际成本
（`γλ/(1+λQ) = 2e9×10/6 ≈ 3.3e9`）远高于指数型与幂函数型，
因此它在最紧预算下就已"不值得"继续省这点质量成本。

**行动项**：这正是题目"讨论成本函数选择对最优解的影响"的**直接答案素材**，
应做成对比表 + 图（三种 g(Q) 下的 `N*, D*, Q*` 随预算变化曲线）。

#### 发现 4：数值实现警告

探针过程中出现 `overflow encountered in exp`、`divide by zero`、`invalid value` 警告。
**行动项**（OPS_SPEC 第 7.1 节的落实）：
- 优化变量必须用 **log 参数化**（`N = exp(x1)`, `D = exp(x2)`），并对 `x` 做 clip；
- `Q` 用 **logit 参数化**并 clip，或直接以 `Q ∈ [1e-6, 1]` 做有界优化；
- 目标函数与约束必须包在 `np.errstate(all="ignore")` 中并返回 `inf` 处理非法点；
- 多起点（≥16）必须做，且要报告**收敛诊断**，避免把局部极小说成全局最优。

> **结论**：Q3 的难度不在"能不能求出来"，而在"**求出来的边界解是否被正确解释**"，
> 以及"**结构性转移的信号是否在正确的预算区间被找到**"。这两点是本题的得分关键。

## Q4 技术演进分析与前沿预测

### 4.1 贡献分解

**目标**：把能力增长拆成**规模扩张**与**非规模技术进步**，给出各自贡献占比（含区间）。

**候选模型**：
```
Score_t = f(scale_t; θ) + g(t; φ) + ε_t
```
- `f`：规模效应（参数 / 算力 / 数据量），如对数或幂律形式
- `g`：非规模技术进步（时间的单调函数，捕捉架构、对齐、数据工程）
- 识别 `g` 需要控制 `scale`，或用**双重机器学习（DML）** 估计技术进步的边际效应

**待填**：分解结果（如"规模扩张贡献 x%，技术进步贡献 y%"）与置信区间。

### 4.2 Loss ↔ Benchmark 桥接

```
Benchmark = h(Loss)
```
候选 `h`：logistic / 分段线性 / 保序回归（单调约束）。
**待填**：用 C5/C6 拟合，报告 R²、残差诊断，以及**映射误差对预测区间的放大倍数**。
**注意**：C5/C6 须按**可比性等级**分层使用。
