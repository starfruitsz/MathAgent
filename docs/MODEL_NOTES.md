## Q1 单点往返运输能力与货箱组批方案

### 1.1 问题结构

每个架次 `p`：`O01 → S_i → O01`（**仅一个服务区**，不得跨服务区组批）。
同一服务区可由多个架次分批服务。

### 1.2 最大安全载荷的反解

**去程载货 q、回程空载**，往返能耗：
```
E_g^T(q; i) = E_g(O01→S_i, q) + E_g(S_i→O01, 0)
```
**能量约束取等号**定义最大安全载荷：
```
E_g^T(q_max; i) = (1 − ρ_g) · E_g^use
```

**为什么必须数值反解**：`L_g(q) = L_g0 − (L_g0−L_gF)(q/Q_g)^(3/2)` 中指数为 3/2，
使能耗对 `q` 非线性且无闭式反函数。**解法**：`E_g^T(q)` 关于 q 单调递增
（载荷越大，等效航程越短、能耗越高），用 **brentq 二分**求解。

**最终载荷还要与硬上限取 min**：
```
q_max^safe = min( 能量反解值 , Q_g , 体积对应质量上限 )
```

**必做验证**：反解后回代，断言 `|E_g^T(q_max) − (1−ρ_g)E_g^use| < tol`。

### 1.3 货箱组批（装箱问题）

对每个服务区 `S_i` 独立求解：把该区的货箱集合划分为最少的架次，满足
- 质量：`Σ_{b∈p} m_b ≤ q_max^safe(g, i)`
- 体积：`Σ_{b∈p} v_b ≤ Q_g^vol`
- 型号选择：可选 3 种机型，**机型也参与决策**

> **待填**：所用装箱算法（FFD / 分支定界 / CP-SAT）、下界、间隙（gap）。

### 1.4 三目标权衡

| 目标 | 定义 |
|---|---|
| 往返架次数 | 总架次数 |
| 总运输能耗 | `Σ_p E_p^T` |
| 累计作业时间 | `Σ_p (飞行时间 + 装卸/周转时间)` |

**待填**：三者是否冲突？给出 Pareto 前沿或加权方案 + **权衡关系或优先关系**的说明。

### 1.5 返航安全余量敏感性（必答）

扫描 `ρ_g`（如 0 → 0.4），输出：
- `ρ_g` — 最大安全载荷曲线（3 机型 × 15 服务区）
- `ρ_g` — 架次数曲线
- `ρ_g` — 总能耗曲线

**待填**：临界点（超过某 ρ_g 后某机型不再可用）及物理解释。

## Q2 异构无人机多点多架次运输调度

### 2.1 决策变量（六元组，须联合确定）

1. 货箱组批
2. **服务区访问顺序**（每架次可访问**一个或多个**服务区）
3. **运输机型** `g`
4. **具体执行无人机**（8 架实体机）
5. **共享电池**分配
6. **各架次开始时刻**

### 2.2 约束

- 货箱不可拆分
- 载质量 / 装载体积
- 返航安全余量 `E_p^T ≤ (1−ρ_g)E_g^use`
- 无人机与共享电池**数量**
- **充电周转**：同一资源任务占用与充电时段**不得重叠**；不同资源可并行
- 时限：**医疗物资期望送达** + **首批保障货箱截止时间**

> ★ 载荷沿架次递减：连续访问多服务区时，每次投送后**从 30 m 作业高度重新爬升**，
> 且后续航段的 `q` 要扣掉已投送的货箱质量。

### 2.3 目标

多目标：配送及时性 + **全部任务完成时间** + 运输能耗 + 架次数

> **全部任务完成时间** = 所有运输无人机完成**最后一个架次并返回 O01** 的**最晚时刻**。

**待填**：多目标处理方式（加权 / ε-约束 / Pareto）与权重依据。

## Q3 通信约束下的运输与中继联合调度

### 3.1 新增决策变量

- 中继无人机的**悬停位置**（平面位置 + 飞行海拔）—— 连续三维变量
- **服务时段**
- **能源组件分配**

### 3.2 连续通信约束（★ 本题最硬的新约束）

> 运输无人机在**爬升、巡航、下降及物资投送**阶段**均应保持连续通信**。

形式化：设架次 p 的轨迹为 `Traj_p(t)`，要求
```
∀ t ∈ [t_start(p), t_end(p)] :  comm_state( Traj_p(t) ) ≠ 中断
```
其中
```
comm_state = 直连   若 A(运输机 ↔ G01) = 1
           = 中继   若 直连不可用 且 A(运输机 ↔ 中继机) = 1 且 A(中继机 ↔ G01) = 1
           = 中断   其余
```

**实现要点**：
- 必须**沿航段逐时刻采样**（不能只查端点）—— 见规范 ADR-007
- **采样步长须做敏感性分析**（步长太大漏判，太小算不动）
- 中继需**两段链路同时可用**，且**不允许多跳**
- 每架运输机同时刻**只由 G01 或一架中继**保障

### 3.3 中继悬停位置

- 悬停位置必须**位于 DEM 覆盖范围内**
- 悬停**离地高度 ≤ 附件规定上限**
- 往返悬停位置的地形净空按航段规则确定（最高点 + 50 m）
- 需满足**返航电量要求**

**待填**：悬停候选点的离散化方式（网格步长）、选址与调度的耦合求解策略。

### 3.4 目标

物资配送及时性 + **联合任务完成时间** + 运输与中继总能耗 + 两类无人机使用架次

> **联合任务完成时间** = 所有**运输无人机和中继无人机**完成最后一个架次并返回 O01 的**最晚时刻**。

## Q4 救援任务分区与资源配置优化方案

### 4.1 硬约束（违反即无效）

- 15 个服务区划分为 **2 组** 与 **3 组** 两种方案
- 每个服务区**必须且只能**属于一个任务组；**每组至少一个服务区**
- ★ **保持 Q3 已确定的货箱组批、服务区访问顺序、运输与中继任务安排、通信保障关系不变**
- ★ **若同一运输架次同时涉及多个服务区，则这些服务区应划入同一任务组**
- 各任务组**仅承担本组**服务区的任务
- **任务执行期间各类资源不得跨组调配**

### 4.2 建模关键：先聚类架次，再归组服务区

因为"同架次的多服务区必须同组"，**不能先分服务区**（会导致方案不可行）。
正确顺序：
```
Q3 方案 → 提取架次集合 → 求"原子单元"（同架次服务区集合）
        → 对原子单元做划分（k = 2 或 3 类）
        → 校验：服务区互不重叠且并集 = 全部 15 个
```
> ★ 若 Q3 中存在一个架次同时服务了本应分属不同组的服务区，则该服务区集合构成
> **不可分的原子单元**。因此**必须先把原子单元求出来再划分**，
> 直接对 15 个服务区做 k-means/枚举会产生不可行方案。

### 4.3 资源核算（每组独立）

| 资源 | 需求 |
|---|---|
| 运输无人机 | 组内架次并行的峰值需求 |
| 共享电池 | 考虑充电周转后的需求（分机型） |
| 中继无人机 | 组内中继任务并行峰值 |
| 中继能源组件 | 考虑充电周转后的需求 |

### 4.4 对比维度（4 项，必答）

| 维度 | 度量 |
|---|---|
| 资源配置规模 | 四类资源总需求（2 组 vs 3 组） |
| **资源冗余** | 现有库存 − 组内需求（逐组、逐类） |
| **组间工作量均衡** | 各组工作量（架次数 / 时长 / 能耗）的方差或最大最小比 |
| **资源缺口** | 负冗余；须给出**原因** |

**待填**：分区方案、四类资源实际数值、冗余与缺口结果、均衡指标。
