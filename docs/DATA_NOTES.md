## 4. 单位换算登记（★ 极易出错）

内部**一律 SI**。读入附件时立即换算，并在此登记：

| 附件单位 | 内部单位 | 换算 | 涉及位置 |
|---|---|---|---|
| km → m | ×1000 | 航程、距离 |
| m → km | /1000 | **★ FSPL 的 D 必须用 km**（内部存 m，代入前除 1000） |
| MHz | 保持 MHz | FSPL 的频率项 |
| min → s | ×60 | 时间、`T_full` |
| cm³ / L → m³ | 换算后统一 | 装载体积（须与机型体积上限同单位比对） |
| Wh / kJ → kWh | 换算后统一 | 能量 |

## 5. 派生数据（`data/processed/`）

由 `src/q0_data/build_processed.py` 与 `src/physics/precompute.py` 生成：

| 文件 | 内容 | 生成者 |
|---|---|---|
| `nodes.csv` | O01 + 15 服务区：原始坐标、**投影坐标**、地面海拔、作业高度 | `build_processed.py` |
| `boxes.csv` | 80 箱：箱号、服务区、质量、体积、类型、时限 | `build_processed.py` |
| `uav_types.csv` | 3 机型参数 | `build_processed.py` |
| `relay_params.csv` | 中继机与能源组件参数 | `build_processed.py` |
| `link_params.csv` | 链路预算参数 | `build_processed.py` |
| **`leg_cache.parquet`** | ★ 全部节点对的 `(d_ij, h⁺_ij, h⁻_ij, t_ij, E_ij)` | `precompute.py` |

> ★ `leg_cache` 是全题的性能关键：Q2/Q3 求解器会反复查询同一航段，
> 必须**只算一次**（见规范 ADR-003）。
