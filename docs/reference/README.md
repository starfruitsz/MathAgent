它由工作区外部放入，并非本项目产出，因此：

1. **移入本目录并改名**，避免与我们的交付物混淆；
2. **禁止**将其结论当作本队结果写入论文；
3. **禁止**直接引用其文字（竞赛查重会判定违规）。

## 使用边界（重要）

**用途确认**：该文件是**第三方 agent 跑出的同题版本**，内部**仍存在较多错误**。
本队将其定位为：

1. ★ **P5 阶段的 Word 文本生成模板** —— 借用其**章节组织、图表排布、摘要写法**；
2. **交叉验证参考** —— 对比数量级，辅助自查。

| 可以做 | 不可以做 |
|---|---|
| 作为**章节结构与排版模板**，用于生成本队 Word 论文 | 把它的表格/数字搬进我们的结果文件 |
| 作为**交叉验证**：看数量级是否与我们独立计算一致 | 抄写其表述、公式推导或图表 |
| 提示我们是否有遗漏的建模角度 | 以它作为学术依据下结论 |
| 借鉴**摘要的写法与信息密度** | 沿用其中**已发现的错误**（见下表） |

题目明确规定：**不得以 AI 输出作为学术依据**，公式与结论须引用正式发表的文献或可核验数据。
第三方 agent 输出既非正式文献、也非本队工作，**只能作为格式模板与自查工具**。

## ★ 已知错误（使用模板时必须规避，不得沿用）

> 以下为本队复核后**确认有问题**的点。生成 Word 时若沿用其表述会直接带错。

| # | 问题 | 本队的正确处理 |
|:--:|---|---|
| 1 | **"能量不约束 A 型"的表述不完整** | 我们的结论是 A 型 **15/15 服务区全部受结构上限 `Q_g` 约束**（不是"能量不约束"，而是"能量从未成为紧约束"）；B 型 14/15、C 型 10/15 |
| 2 | 水平巡航能耗口径未交代依据 | 题目**未给运输机巡航功率**，我们采用"由航程反推" `E=(d/L_g(q))·E_g^use`（**ADR-021**），必须在论文中写明依据 |
| 3 | 多点架次能耗若按"总距离当一段"计算会失真 | 必须**逐段**计算（爬升项 + 载荷递减），见 `physics/energy.py` 与校验器的 `legs` 口径 |
| 4 | 时限可行性未做论证 | 首批时限在本机队下**物理不可行**（前 60 min 最多 8~10 架次 vs 9 个区要求 60 min 内送达），我们给出定量论证（`MODEL_NOTES` 2.3c） |
| 5 | 交接时间按"总箱数 × 站数"计算 | 正确为 **Σ_站(基础交接 + 每箱×该站箱数)**；我们已在校验器中修复此口径错误 |

> 该表随发现持续更新。**发现新错误务必登记在此**，避免后续 agent 误用。

### 参考文稿2 的排版口径（本队已按其整改）

| 要素 | 参考文稿2 的做法 | 本队落地方式 |

## ★ 已知错误（使用模板时必须规避，不得沿用）

> 以下为本队复核后**确认有问题**的点。生成 Word 时若沿用其表述会直接带错。
> **后续 agent 若发现新错误，请登记到本表**，避免下一个 agent 再次踩坑。
> 完整清单（含四问答案与思维链）见 **[`../AGENT_GUIDE.md`](../AGENT_GUIDE.md) 第一节**。

| # | 初稿的问题 | 本队的正确处理 | 落地位置 |
|:--:|---|---|---|
| 1 | **"能量不约束 A 型"的表述不完整** | 正确结论：A 型 **15/15 服务区全部受结构上限 `Q_g` 约束**（即"能量从未成为紧约束"，而非"不约束"）；B 型 14/15、C 型 10/15 | `physics/payload.py` |
| 2 | 水平巡航能耗口径未交代依据 | 题目**未给运输机巡航功率**（只给中继机功率），必须用**由航程反推** `E_hor = (d/L_g(q))·E_g^use`，并在论文中写明依据 | **ADR-021**、`physics/energy.py` |
| 3 | 多点架次能耗按"总距离当一段"计算会失真（能量对距离非线性） | 必须**逐段**计算：每段"爬升项 + 该段载荷下的水平能耗"，载荷沿航段递减 | `physics/energy.py::sortie_energy_kwh` |
| 4 | 时限可行性未做论证 | 必须给**定量论证**：8 架机 / 14 组电池 / 40~50 min 充电 ⇒ 前 60 min 最多 8~10 架次，而 9 个服务区要求 60 min 内送达 ⇒ **物理不可行** | `MODEL_NOTES.md` §2.3c |
| 5 | 交接时间按"总箱数 × 站数"计算（重复计入） | 正确为 **Σ_站(基础交接 + 每箱 × 该站箱数)**，即逐站累加 | `physics/energy.py`、`verify/feasibility.py` |
| 6 | 爬升能耗系数 `0.72` 未说明含义 | 附件列名是"**爬升能耗效率**"，故按**效率**用：`E_up = m·g·h⁺ / η_up`；下降能耗效率为 0 ⇒ **不单独计下降能耗** | **ADR-020** |
| 7 | 把附件 DEM 当成裸地地形 | 附件 DEM 是 **Copernicus GLO-30 DSM（数字表面模型，含植被/建筑）**，按原样使用、不"去建筑"，用于净空与遮挡判定**偏保守** | **ADR-019** |
| 8 | FSPL 单位陷阱（距离用了 m 而非 km） | `L_FSPL = 32.45 + 20log₁₀f(MHz) + 20log₁₀D(**km**)`；内部距离以 m 存储，代入前必须 ÷1000，否则差 60 dB | `comms/link.py::fspl_db` |

## 交叉验证记录（只登记"是否一致"，不引用其表述）

> 目的：若第三方独立算出的量级与我们的独立结果一致，可增强我们对物理层/数据理解的信心；
> 若不一致，则提示我们复查。**记录时只写"我们的值"与"是否吻合"，不誊抄对方内容。**

| 项目 | 我们的独立结果 | 是否吻合 | 说明 |
|---|---|---|---|
| 问题一最优架次数 | **18**（达到下界，可证最优） | 一致 | 我们的下界来自 Martello–Toth 型下界，与启发式逐区相等 |
| A 型最大安全载荷 | **恒为 25 kg**（15/15 全区受结构上限约束） | 一致 | 见 `outputs/q1/tables/q1_1_max_safe_payload.csv` |
| C 型远距离载荷下降 | S008 降至 **58.99 kg** | 量级一致 | 能量约束二分反解，回代误差 5.6e-15 |
| ρ 增大导致架次数上升 | ρ: 0.20→18 架次；0.35→25 架次；0.40 起不可行 | 趋势一致 | 见 `outputs/q1/tables/q1_4_rho_sweep.csv` |
| 总能耗 | **75.07 kWh**（我们的 `single_C` 方案） | 数值不同 | 能耗口径差异（我们按航程反推，见 ADR-021）；**以我们的口径为准并在论文中说明依据** |

> ★ **能耗数值不一致是预期的**：题目附录 2 未给出运输机的巡航功率，
> 我们采用"由航程反推"的口径（ADR-021），第三方可能采用别的口径。
> 论文中必须明确写出所采用的能耗口径与依据，而不是比较绝对值。
